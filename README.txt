SAO — установка игры

Вариант 1 (проще всего): открой sao-offline.html — это вся игра в одном файле, работает без интернета.

Вариант 2 (установка как приложение на телефон/ПК):
1. Загрузи ВСЮ эту папку на любой бесплатный хостинг с HTTPS:
   - Netlify Drop (app.netlify.com/drop) — перетащи папку в окно,
   - или GitHub Pages / Cloudflare Pages.
2. Открой выданную ссылку на телефоне.
3. Android (Chrome): меню ⋮ → «Установить приложение» (или кнопка «Установить игру» в меню игры).
   iPhone (Safari): «Поделиться» → «На экран Домой».
4. Игра запустится на весь экран и будет работать офлайн.
